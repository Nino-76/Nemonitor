# Nemonitor

A simple C program to quickly access information about your system.

## Features
- Operating system and kernel information
- RAM usage statistics (total, used, and available)

## Requirements
- Linux
- GCC

## Compilation
```bash
gcc -Wall -Wextra -std=c11 main.c system_info.c -o nemonitor
```

## Run
```bash
./nemonitor
```
